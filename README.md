# ☕ The Cafe

A simple cafe website built with **HTML and CSS** as one of my early web development projects.

This project was created as a practice project while learning the fundamentals of HTML, CSS, Flexbox, responsive design, and basic page structure.

## 🌐 Live Demo

[View Live Site](https://hadiswebpro.github.io/Cafe/)

## ✨ Features

* Cafe homepage
* About section
* Food and drinks menu
* Expandable menu sections using HTML `<details>` and `<summary>`
* Location section
* Google Maps link
* Responsive layout
* Navigation links between page sections
* Custom styling with CSS
* Hover, active, and visited link states

## 🛠️ Technologies

* HTML5
* CSS3
* Flexbox
* Responsive Design
* Media Queries

## 📚 What I Practiced

This was one of my early projects and helped me practice:

* HTML document structure

* CSS selectors
